# How to open REAL FORGE

The app files are in this repo. Vercel login is blocking the hosted URL.

## Run on your phone or laptop (no login)

1. Download this repo as ZIP from GitHub.
2. Unzip.
3. Open `index.html` then `app.html`.

## Unblock Vercel

Vercel → real-forge → Settings → Deployment Protection → Vercel Authentication → Off.
